A deterministic, standard-library-only Python program that renders a single 1024x1024 PNG summarising the world news of Monday 23 November 2026: COP31 ends with no deal in Antalya; a Russian strike hits flats in Dymer near Kyiv while Ukrainian drones sink a Russian corvette in Libya; Oxfam reports toxic risks across 99% of Gaza; drone strikes hit Khartoum, Sudan; an AI sell-off sinks Asian markets (Nikkei -5.1%, Kospi -5.2%, Taiex -6.2%); US Democrats win 258 House seats, their biggest majority since 1992. Two runs produce byte-identical output. Sources: Reuters, AP, BBC, Al Jazeera and other reports dated 23 Nov 2026.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` if that directory exists, otherwise `./output/entry.png`.
